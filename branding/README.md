# DBW Care Board – Branding Assets

Dieser Ordner enthält unsere Original-Branding-Assets.
Er wird **nie** von upstream (makeplane/plane) überschrieben.

## Verzeichnisse

- `logos/` – Logo-Dateien (SVG, PNG) in verschiedenen Varianten
- `favicons/` – Favicon-Dateien (ico, png)
- `icons/` – PWA/App-Icons

## Anwendung

Die Dateien hier sind die **Quelle der Wahrheit** für unser Branding.
Um sie im Projekt zu verwenden, werden sie an die entsprechenden Stellen
in `apps/*/app/assets/` kopiert (gleicher Dateiname wie das Original).

Siehe CLAUDE.md im Repo-Root für die vollständige Zuordnung der Dateipfade.

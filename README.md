# DBW**CARE** Board

Internes Projektmanagement-Tool von [dbw media](https://dbw-media.de) für die Betreuung von Kundenprojekten.

**Live:** [care.dbw-media.de](https://care.dbw-media.de)

## Was ist das?

DBW**CARE** Board ist ein Fork von [Plane](https://github.com/makeplane/plane) (v1.3.1), angepasst an den Workflow einer Digitalagentur. Kunden erhalten direkten Zugang zu ihrem Projektboard, können Aufgaben erstellen und den Fortschritt verfolgen.

### Erweiterungen gegenüber Plane

- **Zeiterfassung** — Timer und manuelle Einträge pro Issue mit Billing-Status
- **Stundenkontingente** — Monatliche Budgets mit Depot-System und automatischem Rollover
- **Kunden-Reporting** — Automatisierte Monats- und Wochenberichte per E-Mail
- **Gastrolle** — Vereinfachte Oberfläche für Kunden mit geführter Aufgabenerstellung
- **Experten-Team** — Zugewiesene Ansprechpartner pro Kundenprojekt
